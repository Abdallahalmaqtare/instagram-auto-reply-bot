# بوت الرد التلقائي على رسائل انستغرام (نسخة بلا قاعدة بيانات)

بوت يستخدم **Instagram Messaging API الرسمي** (عبر Meta for Developers) للرد
التلقائي على رسائل الدايركت. هذه نسخة مبسّطة عمداً:
- لا قاعدة بيانات
- لا سجل أحداث (Logs)
- الإعدادات تُخزَّن في ملف واحد على القرص (`data/settings.json`) يُعدَّل من لوحة التحكم

## ⚠️ توضيح مهم: GitHub ليس استضافة تشغيلية
GitHub (ومنها GitHub Pages) يخزّن الكود فقط، ولا يستطيع تشغيل خادم يستقبل
Webhook من ميتا على مدار الساعة — GitHub Pages مخصص لصفحات ثابتة فقط. لذلك:
- **GitHub** = مكان تخزين الكود (Repository) فقط.
- **Render** (الخطة المجانية) = من يُشغّل الخادم فعلياً ويعطيك رابط HTTPS ثابت.

الخبر الجيد: بما أننا أزلنا قاعدة البيانات، صار الإعداد على Render أبسط بكثير —
لا حاجة لإنشاء حساب MongoDB Atlas أو أي شيء خارجي، فقط الكود + متغيرات البيئة.

## ⚠️ ملاحظة عن "قسم الطلبات"
الـ API الرسمي لا يعطي صلاحية الرد على رسائل "الطلبات" (Message Requests) إلا
بعد أن يقبلها المستخدم وتنتقل إلى "الأساسي" — فكل رسالة تصل عبر الـ webhook
هي بالتعريف من الأساسي، بلا حاجة لأي فلترة إضافية.

## ⚠️ محدودية هذه النسخة المبسطة
- **عدم التكرار على نفس الشخص** يُحسب في ذاكرة العملية (RAM)، فيُعاد تصفيره
  عند كل إعادة نشر أو إعادة تشغيل للخادم. مقبول تماماً للاستخدام العادي.
- **التأخير قبل الرد** (بالثواني) يُنفَّذ مباشرة داخل العملية النشطة أثناء
  معالجتها لتلك الرسالة، فهو يعمل بشكل موثوق طالما بقيت المدة قصيرة (ثوانٍ
  إلى دقائق قليلة). لا تجعل التأخير طويلاً جداً (ساعات) لأن استضافة Render
  المجانية قد "تنام" بعد حوالي 15 دقيقة من عدم وجود أي طلب HTTP، فيضيع أي
  تأخير أطول من ذلك لم يُنفَّذ بعد.
- الإعدادات تُحفظ في ملف على القرص يبقى طالما لم تُعِد نشر الكود من جديد؛
  إعادة نشر جديدة على Render تصفّر الملف للقيم الافتراضية (لأن القرص المجاني
  غير دائم عبر عمليات النشر). إن أردت لاحقاً حفظاً دائماً 100% حتى مع كل
  إعادة نشر، الحل هو إضافة قاعدة بيانات مجانية بسيطة — لكن هذا خارج نطاق هذه
  النسخة المبسطة كما طلبت.

## الخطوة 1: إعداد حساب Meta for Developers

1. حوّل حساب انستغرام إلى **Professional (Business أو Creator)**.
2. أنشئ صفحة فيسبوك (Page) واربطها بحساب الانستغرام من إعدادات الصفحة → Linked Accounts.
3. اذهب إلى https://developers.facebook.com → **My Apps** → **Create App** → نوع **Business**.
4. أضف منتج **Instagram** من لوحة التطبيق وأكمل ربط الحساب.
5. من صفحة إعداد Instagram:
   - ولّد **Access Token** → احفظه في `IG_ACCESS_TOKEN`.
   - من Settings → Basic انسخ **App Secret** → احفظه في `IG_APP_SECRET`.
6. من قسم **Webhooks**:
   - Callback URL: `https://YOUR-RENDER-URL.onrender.com/webhook`
   - Verify Token: أي نص تختاره → ضعه في `IG_VERIFY_TOKEN`.
   - اشترك في حقل `messages` على الأقل.

> في وضع التطوير (Development Mode) يعمل التطبيق فوراً على الحسابات المضافة
> كـ Testers/Admins بدون مراجعة من ميتا — كافٍ لحسابك الخاص أو التجاري.

---

## الخطوة 2: رفع المشروع إلى GitHub

1. أنشئ مستودعاً جديداً (Repository) على GitHub.
2. ارفع محتوى هذا المجلد إليه (ملف `.env` نفسه **لا يُرفع** — موجود في `.gitignore`).

## الخطوة 3: النشر على Render (مجاني)

1. في https://render.com → **New +** → **Web Service** → اختر مستودعك.
2. الإعدادات:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
3. أضف متغيرات البيئة (Environment) من ملف `.env.example`:
   `IG_ACCESS_TOKEN, IG_VERIFY_TOKEN, IG_APP_SECRET, ADMIN_USERNAME, ADMIN_PASSWORD`
4. بعد نجاح النشر سيكون رابطك مثل: `https://instagram-auto-reply-bot.onrender.com`
   - رابط الـ Webhook (يوضع في لوحة Meta): `.../webhook`
   - لوحة التحكم: `.../admin` (سيطلب المتصفح اسم المستخدم وكلمة المرور اللذين حددتهما)

---

## استخدام لوحة التحكم

افتح `https://YOUR-RENDER-URL.onrender.com/admin` وسجّل دخولك، ومن هناك:
- تفعيل/تعطيل البوت بالكامل
- اختيار وضع الرد (على الجميع / كلمات مفتاحية فقط) وإضافة قواعد الكلمات
- ضبط التأخير (ثابت أو عشوائي) بالثواني — الافتراضي العشوائي: 3 إلى 5 ثوانٍ
- ضبط منع تكرار الرد وساعات العمل والرد البديل خارجها
- إدارة القائمة البيضاء والسوداء (بمعرفات IGSID)

## بنية المشروع
```
src/
  config/settingsStore.js   قراءة/كتابة الإعدادات من ملف data/settings.json
  services/metaApi.js       إرسال الرسائل + التحقق من توقيع Meta
  services/replyEngine.js   منطق اتخاذ القرار والتأخير (setTimeout مباشر)
  routes/webhook.js         استقبال الرسائل من Meta
  routes/admin.js           API لوحة التحكم (محمي بـ Basic Auth)
  server.js                 نقطة الدخول
public/index.html           لوحة التحكم (واجهة)
```
